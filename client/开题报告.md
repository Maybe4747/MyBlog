# 成都锦城学院毕业论文（设计）开题报告

## 题目
基于React和Express的个人职业资料管理平台的设计与实现

## 选题意义
随着信息化与职业发展的深度融合，个人职业资料的管理已成为求职者、职场人士及兴趣爱好者的重要需求。传统的简历与作品集展示方式单一、更新不便，难以满足当代职场多样化、即时化的展示与交流需求。

根据调研，国内职场人士对现有平台在资料管理、展示方式、社交互动等功能上的不足存在不满。职场社交平台在文化本地化的适配上仍然存在较大差距，尤其在资料上传、隐私保护和个性化展示等方面。

本项目旨在设计并实现一个基于React与Express的个人职业资料管理平台，将多媒体资料集中管理、轻社交互动、搜索与权限控制有机结合，为用户提供高效、便捷且可个性化定制的职业发展支持工具。

## 国内外研究现状概述
### 国外现状
- **LinkedIn**: 全球领先的职业社交平台，支持职业信息展示、社交拓展和职业机会获取
- **Behance**: 创意类作品展示平台，提供专业化的作品集展示与交流空间
- **局限性**: 中文语境下本土化适配有限，文化差异明显，功能支持较为基础

### 国内现状
- **脉脉**: 偏向职业社交，强调人脉关系构建
- **BOSS直聘**: 以招聘撮合见长，实时沟通提升效率
- **局限性**: 多媒体资料管理深度不足，个性化展示支持有限

现有平台在多样化资料展示、个性化权限控制与全文检索等方面仍有不足，缺乏能同时满足职业成长记录、兴趣展示与社交互动需求的综合性平台。

## 主要研究内容
1. **账户系统**: 用户注册、登录、JWT身份认证和权限管理，使用bcrypt加密算法保护密码安全

2. **个人资料管理**: 
   - 支持PDF、DOCX、JPG、PNG、MP4等多种文件格式
   - 支持标签与描述添加
   - 三级权限控制：公开、仅关注者可见、私密

3. **社交互动功能**:
   - 关注、点赞、评论、@提及与表情互动
   - 采用WebSocket技术实现实时消息推送

4. **搜索功能**:
   - 基于MongoDB实现全文检索与模糊匹配

5. **消息通知系统**:
   - 实时行为提醒
   - 免打扰时段个性化设置

## 拟采用的研究思路
### 研究方法
1. **需求分析与用户画像**: 通过调研与用户访谈明确核心需求
2. **系统架构设计**: 设计UI布局、API结构、数据库与缓存方案
3. **模块化开发**: 按功能模块逐一开发，确保稳定性

### 技术路线
- **前端**: React + Tailwind CSS + React Router
- **后端**: Node.js + Express + RESTful API
- **数据库**: MySQL存储
- **搜索**: MySQL
- **实时通信**: WebSocket (Socket.IO)

### 可行性论证
采用的技术方案均为当前主流且成熟的技术，具有丰富的开发经验和案例支持，能够有效降低实施风险。
